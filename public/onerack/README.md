# OneRack equipment artwork

These passive SVG assets were extracted from the user's original OneRack/rack-elevation.html text/svg template blocks on October 7, 2026. Original source files were read only.

The Pro renderer chooses the Cisco 92348, Cisco 9336 and GrandTwin front/rear templates. Pocket equipment uses the same horizontal face rotated -90 degrees, matching the source renderer. Other catalog equipment keeps a labeled fallback until artwork is supplied. Template scripts and external integrations are not included.
